# 实验2：Streamlit学生成绩数据看板
> 仓库：exp2‑streamlit‑student‑score‑dashboard

## 项目简介
基于 Streamlit + Pandas + Plotly 实现班级学生成绩可视化看板，包含3个版本代码：
1. score_dashboard.py 基础版：数据生成、清洗、基础图表
2. score_dashboard_advance.py 进阶版：侧边筛选、数据联动、TOP10排行榜
3. score_dashboard_extend.py 拓展版：阈值预警、明暗主题切换、数据导出
